## Install or update


1. Quit Papercut Desktop or RushRoom Desktop from its menu-bar menu if running.
2. Open the DMG and drag **RushRoom Desktop** into **Applications**.
3. Open RushRoom Desktop. If macOS blocks it, follow [Apple’s first-launch instructions](https://support.apple.com/en-us/102445) in **System Settings → Privacy & Security → Open Anyway** after attempting to open it.
4. Return to RushRoom in your browser and choose **I’ve installed it · Retry**. Allow the browser’s device-connection permission when asked. Run one helper at a time.


Desktop connects RushRoom to footage on your Mac. Originals stay on the Mac; review media uploads to your Room. Existing local mappings, preferences and saved import progress are preserved. Keep the existing Application Support data.


Producers can review footage and export **Send to an Editor** XML in the browser without Desktop or originals. Desktop is needed for local footage import and original-media operations.
