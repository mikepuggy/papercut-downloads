This is an **unsigned, unnotarized milestone preview** for Macs with Apple silicon (M1 or newer). Intel Macs are not supported by this build. You do not need a GitHub account to download it.

## Install or update

1. If Papercut Desktop is already running, quit it from its menu-bar menu.
2. Open the downloaded DMG and drag **Papercut Desktop** into **Applications**, replacing the previous version if needed.
3. Open Papercut Desktop. If macOS blocks it, follow [Apple’s first-launch instructions](https://support.apple.com/en-us/102445) in **System Settings → Privacy & Security → Open Anyway** after attempting to open it.
4. Return to Papercut in your browser and choose **I’ve installed it · Retry**. Allow the browser’s device-connection permission when asked.

Desktop connects Papercut to footage on your Mac. Your originals stay on the Mac; review media uploads to your Papercut project. Local mappings and saved import progress are preserved when updating.

Producers can review footage and export **Send to an Editor** XML in the browser without Desktop or original files. Desktop is needed for local footage import and original-media operations.

This repository contains installers and download instructions. The automatically listed source archives contain this download documentation, not the Papercut application project.
